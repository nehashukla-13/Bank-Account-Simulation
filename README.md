# Bank-Account-Simulation
Java OOP Bank Account Simulation 

About

This project is a simple bank account simulation developed using Java and Object-Oriented Programming (OOP).

Features

- Check account details and balance
- Deposit money
- Withdraw money
- View transaction history
- Validate invalid amounts and insufficient balance

Concepts Used

- Classes and Objects
- Encapsulation
- Inheritance
- Method Overriding
- Constructors
- ArrayList
- User Input using Scanner

How to Run

1. Open "Main.java" in a Java IDE such as Jvdroid.
2. Compile and run the program.
3. Follow the menu displayed on the screen.
